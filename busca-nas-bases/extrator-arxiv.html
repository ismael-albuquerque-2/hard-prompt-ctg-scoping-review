Sobre o Extrator de Resultados arXiv

O que é e qual problema resolve?

O Extrator de Resultados arXiv é uma aplicação client-side em Vanilla JS. Sua função é atuar como uma interface direta de pesquisa massiva de preprints na base de dados arXiv. Ele recebe strings de busca, mas que seguem a sintaxe HTTP da API ArXiv. Ele devolve um arquivo XML retornado pela API.

Pré-requisito Obrigatório

Por realizar requisições de um arquivo local diretamente para export.arxiv.org, o navegador bloqueará a chamada devido às políticas de segurança de origem cruzada (CORS). É obrigatório instalar e ativar uma extensão do tipo "Allow CORS" no navegador para utilizar a ferramenta.

Como Usar

A API do arXiv não aceita textos fora da sintaxe adequada. A string inserida na área de texto deve seguir regras rígidas:

  • Prefixo Inicial: A instrução deve obrigatoriamente começar com search_query=.
  • Distribuição de Campos: A API não entende escopos agrupados como all:("A" OR "B"). O prefixo deve ser distribuído termo a termo: (all:"A"+OR+all:"B").
  • Formatação de URL: Espaços entre termos e operadores lógicos devem ser convertidos em sinais de adição (+).
  • Operadores: Devem ser em letras maiúsculas e encapsulados pelos sinais de adição (ex: +AND+, +OR+).
  • Parâmetros de Controle: A string deve terminar definindo a paginação e o limite, como &start=0&max_results=1000.
  • Atenção aos Limites: Embora o limite teórico da API seja 30.000 resultados, nos testes realizados, colocar esse valor causou erro HTTP 500. Ao reduzir para 1.000, a requisição funcionou normalmente. Recomenda-se manter o limite em torno de 1.000.

Saiba mais consultando a documentação oficial da API do ArXiv em: https://info.arxiv.org/help/api/user-manual.html

Exemplo Prático (Input válido)

search_query=(all:"LLM"+OR+all:"ChatGPT")+AND+(all:"prompt"+OR+all:"zero-shot")&start=0&max_results=1000

Comportamento de Saída (Output)

Após o clique, a interface aguardará a resposta (o que pode levar de 5 a 20 segundos para grandes volumes). Para reduzir o escopo desse programa, ele não realiza o parse visual do XML; ele transforma o texto bruto retornado em um Blob em memória e força o download de um arquivo físico nomeado como arxiv_resultados_[timestamp].xml. Esse arquivo é o xml com os resultados da pesquisa, retornado pela API.
